# Scrapbook Wulan ♡

Website scrapbook romantis untuk Wulan — dibuat dari foto-foto yang diberikan.

## Cara upload ke GitHub Pages

1. Buat repository baru di GitHub.
2. Upload **semua isi folder ini** (bukan file ZIP-nya saja).
3. Pastikan `index.html` ada di halaman utama repository.
4. Buka **Settings → Pages**.
5. Pada Source pilih **Deploy from a branch**, pilih branch `main`, folder `/ (root)`, lalu Save.
6. Tunggu beberapa saat sampai GitHub memberikan alamat website.

## Lagu

Website sudah menyiapkan tombol untuk lagu **"Itulah Kenapa"**, tetapi file audio tidak disertakan.

Kalau kamu punya file MP3 yang legal untuk digunakan, rename menjadi:

`itulah-kenapa.mp3`

lalu masukkan ke folder:

`assets/itulah-kenapa.mp3`

Setelah itu tombol musik akan bekerja.

> Jangan upload lagu berhak cipta yang kamu tidak punya izin untuk didistribusikan.
